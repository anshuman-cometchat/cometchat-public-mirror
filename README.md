# CometChat Flutter UIKit — staging mirror

**This is not a product repository.** It is a throwaway target used to rehearse the
release pipeline of `cometchat-team/chat-uikit-flutter` without writing to the real
public repository.

`release-to-public.yml` resolves one of three modes. Only `staging` writes here:

| Mode | Trigger | Target |
|---|---|---|
| production | release PR merged into `master-v6` | `cometchat/cometchat-uikit-flutter` @ `v6` |
| **staging** | push to `ci-test/**`, or any non-dry-run dispatch | **this repo** @ `v6` |
| dryrun | manual dispatch (the default) | nothing is pushed anywhere |

Anything on the `v6` branch here was generated by a pipeline rehearsal and may be
incomplete, stale, or deliberately broken. For the real UI Kit, see
[cometchat/cometchat-uikit-flutter](https://github.com/cometchat/cometchat-uikit-flutter).

Versions published here carry a `-citest.<run>` suffix so they can never be mistaken
for a release.
